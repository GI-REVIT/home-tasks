# משימות הבית

מערכת אישית לניהול משימות בית: משימות חד-פעמיות וחוזרות, סימון ביצוע, היסטוריה, וסיכומים במייל.

## מבנה הפרויקט

| קובץ | תפקיד |
|---|---|
| `index.html` | דף הראשי: כניסה והמסך עצמו |
| `css/style.css` | העיצוב (RTL, מותאם למחשב ולטאבלט) |
| `js/config.js` | פרטי החיבור ל-Supabase |
| `js/app.js` | לוגיקת הכניסה והיציאה |
| `supabase/schema.sql` | טבלאות, הרשאות ואינדקסים בבסיס הנתונים |

## הקמה (חד-פעמית, כ-15 דקות)

### 1. יצירת פרויקט ב-Supabase
1. היכנסי ל-https://supabase.com והירשמי (מסלול Free).
2. לחצי על **New project**. בחרי שם (למשל `home-tasks`), אזור שרת קרוב, וסיסמה למסד הנתונים. שמרי את הסיסמה במקום בטוח.
3. המתיני עד שהפרויקט מוכן.

### 2. יצירת הטבלאות
1. בתפריט השמאלי: **SQL Editor** → **New query**.
2. העתיקי את כל התוכן של `supabase/schema.sql` והריצי עם **Run**.

### 3. הגדרת כניסה
1. **Authentication → Sign In / Providers**: ודאי ש-Email פעיל.
2. **Authentication → Sign In / Providers → Email**: כבי את **Allow new users to sign up** (ללא הרשמה נוספת). כך רק החשבון שתיצרי יוכל להתחבר.
3. **Authentication → Users → Add user → Create new user**: הזיני את המייל והסיסמה שלך.

### 4. חיבור האתר לשרת
1. **Project Settings → API**: העתיקי את **Project URL** ואת **anon public key**.
2. פתחי את `js/config.js` והחליפי את שני הערכים.

> **חשוב:** המפתח `service_role` לא מוכנס לשום קובץ באתר. הוא נותן גישה מלאה לנתונים. ה-`anon key` מותר לשימוש בדפדפן, כי ההגנה נאכפת בבסיס הנתונים באמצעות ה-Row Level Security שנוצר בסכמה.

### 5. הרצה מקומית לבדיקה
אפשר לפתוח את `index.html` בדפדפן. בטאבלט או במחשב אחר יש לעלות לאחסון אונליין (ראו שלב הפרסום).
